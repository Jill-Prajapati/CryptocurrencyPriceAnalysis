# Cryptocurrency Price Analysis And Prediction

## Overview

This project analyzes historical cryptocurrency price data and uses machine learning techniques to predict future cryptocurrency prices.

The project focuses on data preprocessing, exploratory data analysis, time-series analysis, feature engineering, model development, and evaluation.

## Objectives

* Analyze historical cryptocurrency price trends.
* Explore patterns and relationships within the dataset.
* Prepare and transform data for machine learning.
* Develop a model to predict cryptocurrency prices.
* Evaluate the model's prediction performance.

## Tools & Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* XGBoost
* Time Series Analysis

## Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Time-Series Data Preparation
6. Model Development
7. Model Prediction
8. Model Evaluation
9. Actual vs Predicted Price Analysis

## Key Analysis

The project analyzes:

* Historical price movements
* Opening, closing, high and low prices
* Trading volume
* Price trends over time
* Relationships between different market variables
* Actual vs predicted prices

## Model

An XGBoost-based machine learning model was developed to predict cryptocurrency prices using historical market data.

The model's performance was evaluated by comparing the predicted prices against the actual prices.

## Results

The model predictions were compared with the actual cryptocurrency prices to evaluate how effectively the model captured historical price patterns.
